# Why restarting fixes things

A computer's memory (RAM) slowly fills with clutter: leaked memory, stuck processes, and half-finished states.

Think of a desk covered in papers. You can keep working, but finding anything gets slower.

A restart wipes RAM and starts every program from a clean, known state.

Bugs that only live in memory, like memory leaks, vanish. Bugs saved on disk survive.

Takeaway: "turn it off and on again" resets state, which is why it fixes so many odd problems.
