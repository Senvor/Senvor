# Why restarting fixes things

Computers slowly collect clutter: leftover data in memory, programs that never quite
released what they borrowed, and tiny errors that pile up over time.

Think of a desk covered in papers. You can keep working, but finding anything gets
harder. A restart clears the desk: memory is wiped and everything starts from a clean,
known state.

Bugs like memory leaks and stuck processes live only in that temporary state, so
rebooting makes them vanish, even though the underlying cause is still in the code.
