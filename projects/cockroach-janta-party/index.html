What I built

A responsive archive site for the Cockroach Janta Party, an internet-born youth movement in India, with official website and petition links. I went for a papery, aesthetic look instead of a typical modern site.

What I learned

Advanced CSS layouts, responsive design techniques, visual storytelling through UI, and some JavaScript.
