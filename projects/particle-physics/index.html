Particle Physicslive

A gravity simulation where particles pull on each other like tiny planets.

  • p5.js
  • JavaScript

What I built

A gravity simulation in p5.js where every particle pulls on every other one based on mass and distance, so they sling each other around and form little chaotic solar systems in the browser. Built by following Hack Club's Particle Physics workshop.

What I learned

Built to level up my programming and explore what modern web tools can do creatively.
